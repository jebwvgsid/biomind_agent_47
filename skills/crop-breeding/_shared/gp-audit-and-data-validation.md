# 预测审计与矩阵共同核验

## A. 任务范围与证据

1. 按用户要求区分数据/设计审计、实际运行审计和模型执行。只请求审计时完成可检查的输入、设计与环境事实及后续计划；缺少训练资源只影响依赖它的执行阶段。数据解析、对齐和 QC 可以支持审计，不能冒充指定模型结果。
2. 逐项记录证据位置、直接事实、推断和影响，使用“设计存在明确问题”“已证实实际泄漏”“证据不足，无法判定实际泄漏”“在已检查范围内未发现泄漏”四类判定。设计表证明声明；代码证明实现逻辑；声称实际发生泄漏还需把实现、调用身份和运行产物关联起来。可同时报告“设计声明符合要求，实现未核验”。
3. 先解释 fold 字段属于外层评估、内层调参、权重生成还是 OOF 预测，再核对相应训练成员和使用的标签。相同 fold_id、随机种子或 True 标志不能单独证明训练成员、泄漏或安全。不同模型使用相同外层折可以是正确比较；没有额外外部测试集不自动使外层 CV 无效。
4. 对每个外层测试折追踪所有影响预测的学习过程：插补/标准化、特征筛选、GWAS 权重、超参数/早停、基础模型和融合器。测试表型不得越过该评估边界；预测时可获得的无标签信息按声明的归纳/传导设定另行判断。OOF 只说明预测与其生成模型的关系，不能自动证明后续融合评估独立；通常在外层训练集内生成内层 OOF 并拟合融合器。
5. 没有训练、权重或预处理记录时，不编造成员，也不把缺证据判成已安全。零缺失率或未提供 scaler 不能证明此前没有插补/标准化泄漏。仅在指定输入、相关产物与直接引用中补查，写明最小证据缺口并完成独立可做部分。

## B. 矩阵与标识

1. 记录原文件身份、分隔符、原始表头、缺失值规则、行列数和标签来源；分别识别 ID 字段、注释行和元数据列。预览用于判断格式，最终样本/特征统计须覆盖全量输入。
2. 用格式/schema、行列标签与权威样本清单共同确定方向，并交叉核对两轴的全量匹配。目标工具要求的内部方向不证明源文件方向；不能凭“标记通常较多”或某轴匹配数较大就决定转置。两轴均合理或均不匹配时写明歧义。
3. 零交集或异常减少时，先复核另一轴、表头/首条数据、分隔符、ID 列和已有明确映射，再判缺失映射或真实不匹配。ID 按字符串保留；不能无依据改大小写、去前导零、截断或模糊匹配。必要清理保留原值映射并检查碰撞。
4. 区分原始显示标签、内部技术键与生物身份。重复特征表头不能直接用于名称选列或自动去重；用“源文件哈希＋原列位置”等可追溯唯一技术键保存每个原位置及其值，并保留原标签/注释。技术键只保证文件内身份，不证明基因、位点、同一生物特征或跨文件对应；合并/注释需另有可信映射。
5. 按已验证样本 ID/观测关系显式重排或连接，检查键的唯一性、预期连接关系及顺序。多条表型观测关联唯一基因型通常是多对一；记录连接前后观测数与未匹配项，避免笛卡尔积和静默丢行。不能以行数或集合相同代替对应。
6. 特征账本同时记录原位置、内部键、原标签、保留/排除阶段与原因。检查输出列数以及覆盖的不同原列位置数；重复抽取同一原列不能算作保留多个不同特征。对齐后核验数值矩阵形状、技术索引唯一性和实际样本/特征顺序，原始、保留、排除原位置应对得上。
7. 先定义训练、验证、测试和待预测成员，再按各阶段允许的表型构建训练集。无表型目标不能因 dropna 或与训练表型求交而丢失；文件含测试表型不表示可用于训练。

## C. 重复观测与泛化目标

1. 区分基因型 ID、环境 ID 与观测键，按提供的地点、年份、处理、区组、重复等语义判断。相同 sample × environment 或相同 trait 不证明重复导入；没有重复/区组列也不证明每单元只有一条观测。语义不足时保留原行并记录不确定性，不默认去重、取第一条或取均值。
2. 删除须有重复导入等明确依据；聚合须有任务/模型依据，记录原始数量、方法与权重。分别报告原始观测数、实际参与拟合观测数、样本 × 环境单元数及不同环境数，报告须与脚本实际结果一致。未知重复结构会限制独立性、标准误或泛化解释，不自动阻止结构 QC。
3. 环境时序另建键，检查环境、日期/时间、生育期、变量、单位及传感器/重复字段；区分日内多次测量与重复导入，并说明计算窗口均值的时间/观测权重。
4. 预测新基因型时隔离其相关观测；预测新环境时按实际环境定义隔离；二者皆新时同时满足。已知基因型在缺失环境中的预测可按设计使用其他环境的历史观测。指标/窗口选择和表型推导的训练目标也遵守同一评估边界。
