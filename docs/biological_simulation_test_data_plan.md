# Biological Simulation And Public Test Data Plan

This project now keeps benchmark questions, answers, known issues, data-source notes, and data scripts under:

```text
benchmarks/biomind_agent_benchmark/
```

Skill folders should not own simulation or benchmark-data generation scripts.

## Active Data Policy

Only two active test-data sources are recommended:

- Professional simulation with `msprime`.
- Downloaded public/database subsets with source URLs, checksums, subset rules, and answer keys.

Hand-written NumPy/Pandas toy fixtures are deprecated and kept only under `benchmarks/biomind_agent_benchmark/scripts/legacy/` for traceability.

## Active msprime Generation

```bash
python benchmarks/biomind_agent_benchmark/scripts/generate/generate_msprime_fixtures.py \
  --outdir results/linux_professional_synthetic \
  --seed 20260529
```

Main outputs:

```text
results/linux_professional_synthetic/msprime/genotype_matrix.tsv
results/linux_professional_synthetic/msprime/phenotype.tsv
results/linux_professional_synthetic/msprime/gwas_summary.tsv
results/linux_professional_synthetic/msprime/marker_annotation.tsv
results/linux_professional_synthetic/msprime/msprime_variants.vcf
results/linux_professional_synthetic/msprime/haplotypes.fasta
results/linux_professional_synthetic/msprime/simulation_truth.tsv
```

The genetic variation, VCF, and haplotypes are generated by `msprime`. Phenotype and GWAS-like p-values are BioMind-controlled truth labels derived from simulated genotypes.

## Active Crop Smoke Test

```bash
python benchmarks/biomind_agent_benchmark/scripts/run/run_msprime_crop_gp_smoke.py \
  --fixture-dir results/linux_professional_synthetic \
  --outdir results/linux_msprime_crop_gp_smoke \
  --seed 20260529
```

This tests:

- `crop-genomic-prediction`
- `crop-gp-waiter-transformer` lightweight weighted runner

It does not fabricate multi-omics, GxE, transcriptome, SV, or pangenome toy data. Those workflows should use user-provided data or downloaded/paper-specific data sources.

## Public Downloaded Data

```bash
python3 benchmarks/biomind_agent_benchmark/scripts/download/download_public_demo_fixtures.py \
  --outdir benchmarks/biomind_agent_benchmark/fixtures_public \
  --rawdir .biomind/public_raw

python3 benchmarks/biomind_agent_benchmark/scripts/validate/validate_public_demo_fixtures.py
```

The downloader currently supports small public/demo subsets such as PBMC3k, UCSC hg38 chrM, and a cooler example when dependencies are available.
