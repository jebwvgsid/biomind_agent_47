技术路线图与记忆系统工作流程图

BioMind 面向生物信息学长流程分析，目标不是替代 Seurat、HiCExplorer 等领域算法， 而是构建一个可执行、可审计、可恢复的智能体基础设施。

3 Workflows scRNA 标准分析、scRNA ingest-QC、Hi-C TAD 分析模板
5 Memories Core、Task Summary、Session Archive、Wiki、RAG 分层协同

一、BioMind 技术路线图

路线从“用户自然语言目标”出发，经由任务路由、领域知识约束、状态机编排、安全执行和结果监督， 最终沉淀为可检索、可追溯的项目记忆。

1

问题定义与需求澄清

识别任务类型、输入数据、分析目标和缺失信息，避免模型直接猜测参数。

  • Consultant 需求总结
  • 任务语义：样本、路径、分辨率、比较组
  • 必要时进入 AskUser
2

领域知识结构化封装

将生物信息学流程固化为可发现、可加载、可验证的 Skill 和 Workflow。

  • SkillManager 扫描与匹配技能
  • WorkflowManager 阶段化模板
  • RAGFlow 检索 SOP、工具与错误库
3

状态机智能体编排

用 LangGraph 将计划、审批、生成、执行、监督和安装组织成可中断闭环。

  • Planner 生成可审核计划
  • Generate 输出受控动作标签
  • 每轮只推进一个逻辑步骤
4

安全执行与环境复用

执行前进行风险分析，安装行为委派子智能体，避免环境污染和危险命令。

  • RiskAnalyzer 与人工确认
  • Executor 运行 Bash / Python / R
  • PackageManager 注册环境和 shim
5

执行后监督与纠错

把“命令退出码为 0”和“科学分析有效”区分开，捕捉空输出、静默失败和参数风险。

  • RuleEngine 快速规则检查
  • LLMReviewer 科学性审查
  • 判决：PASS / WARN / RETRY / ESCALATE
6

分层记忆与可恢复评估

将执行事件、任务摘要、项目事实和外部知识分层管理，支撑跨会话恢复。

  • SessionArchive 是事件源
  • Wiki claims 绑定证据
  • 恢复能力、证据完整性和检索质量评估
阶段 A：领域调研与需求建模 抽象长流程任务痛点：上下文遗忘、工具幻觉、环境依赖、错误恢复和证据链缺失。
阶段 B：核心系统实现 完成主状态机、Skill/Workflow、执行器、Supervisor、Installer 和持久化状态。
阶段 C：记忆系统强化 构建 Core / Task / Archive / Wiki / RAG 五层记忆，并实现证据化 Wiki ingest。
阶段 D：中期后验证 围绕 scRNA、TAD 和工具安装失败场景，评估恢复率、重复执行率和证据完整率。

四、答辩讲解要点

下面的表述可以配合上面三张图展开，重点突出系统创新点和中期完成度。

口头说明
1. 为什么需要 BioMind

生物信息学任务不是单轮问答，而是长流程科研计算。系统要知道任务做到哪一步、产物在哪里、错误如何恢复，并能说明结论来自哪条证据。

2. 为什么用状态机

LangGraph 将智能体行为拆成节点，避免模型一次生成多步命令。每一步都经过计划、执行、观察和监督，失败后可回到 Generate 修复。

3. 为什么要 Skill / Workflow

Skill 把领域流程、环境、脚本路径和输入输出约束固化下来；Workflow 把 scRNA、TAD 这类长任务拆成阶段，降低工具幻觉和越阶段执行风险。

4. 记忆系统的创新点

BioMind 没有把所有历史都塞进向量库，而是把稳定规则、任务摘要、会话事件、项目 Wiki 和外部 RAG 分层，长期事实必须绑定证据。

5. 安全与可审计

执行前有命令风险分析和人工确认；执行后有 Supervisor 审查；执行过程、stdout/stderr、产物路径和审查结论进入持久化记录。

6. 中期后的验证方向

围绕真实 scRNA 和 TAD 任务，评价中断恢复成功率、关键参数召回率、重复执行比例、Wiki evidence 缺失率和错误修复复用效果。

五、风险控制与评价指标

答辩时可以用这一页说明系统不仅能“跑”，还考虑了科研计算中的风险、复现和质量评价。

补充页

恢复能力

  • 中断后继续执行成功率
  • 已完成步骤重复执行比例
  • 关键路径与参数召回率

执行质量

  • Supervisor RETRY 修复成功率
  • 空输出、静默失败捕捉率
  • 计划步骤完成率

记忆质量

  • Wiki claim evidence 完整率
  • Core / Wiki 边界违规数
  • 相关记忆检索命中率

安全合规

  • 危险命令拦截与确认记录
  • 密钥脱敏覆盖率
  • 路径逃逸和交互阻塞防护
