# Optional PacBio SV with pbsv

Use this skill only for PacBio-specific pbsv workflows. For generic long-read SV, start with `genomics/long-read-sv-sniffles2`.

## Execution Guidance

Align PacBio reads if no suitable BAM exists:

```bash
pbmm2 align "${REFERENCE_FASTA}" "${PACBIO_FASTQ}" \
  "${OUTDIR}/02.mapping/${sample}.pbmm2.bam" \
  --sort -j "${THREADS:-8}" --preset SUBREAD
samtools index "${OUTDIR}/02.mapping/${sample}.pbmm2.bam"
```

For HiFi/CCS reads, use the pbmm2/pbsv preset documented by the installed version and record it in the report.

Discover and call:

```bash
pbsv discover "${BAM}" "${OUTDIR}/03.variant_calling/${sample}.svsig.gz"
pbsv call "${REFERENCE_FASTA}" \
  "${OUTDIR}/03.variant_calling/${sample}.svsig.gz" \
  "${OUTDIR}/03.variant_calling/${sample}.pbsv.vcf"
```

Use a tandem repeat BED only when provided or generated by a documented pbsv utility; do not invent one.

## Outputs and Validation

- `03.variant_calling/<sample>.svsig.gz`.
- `03.variant_calling/<sample>.pbsv.vcf`.
- `05.summary/pbsv_sv_counts.tsv`.

```bash
test -s "${OUTDIR}/03.variant_calling/${sample}.pbsv.vcf"
grep -v '^#' "${OUTDIR}/03.variant_calling/${sample}.pbsv.vcf" |
  awk -F'\t' '{print $8}' | tr ';' '\n' | grep '^SVTYPE=' | sort | uniq -c \
  > "${OUTDIR}/05.summary/pbsv_sv_counts.tsv"
```

Common blockers include non-PacBio input, missing pbmm2/pbsv runtime, CPU instruction incompatibility, and reference mismatch.
