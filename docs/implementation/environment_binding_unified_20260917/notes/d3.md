# D3 — capability 声明的参考 bundle 验证与极小真实工具链

生产增量为 `agent_core/genomics_reference_bundle.py` 及 `semantic_completion.evaluate_boolean_predicates` 的已登记 parser 分支。最终 mapping Skill 的 `reference_bundle_valid` boolean predicate 沿现有 capability → StepEffect → Supervisor semantic report → CommitStep 重算，不向通用 artifact gate 硬编码 WGS 全局配对。Skill 由主任务独占写入。

固定 v1 从本步骤明确使用的唯一 `reference_fasta` 输入和唯一正式 immutable directory output 解析路径，兼容已有 `resource_uses` 输入索引及 Plan-local output。不从代码、目录扫描或自由产物名猜身份。缺 source role、多 bundle、非目录、源/输出重叠给具体诊断。

所选 BWA 0.7 bundle 布局为 `reference.fa`、`.fai`、`reference.dict` 及 `reference.fa.{amb,ann,bwt,pac,sa}`。验证源与副本 SHA-256；FASTA contig 顺序/长度、FAI 五列（含字节 offset/wrapping）；dictionary SN/LN/M5；BWA ANN contig/offset/length/ambiguity 数，AMB 位置/长度/符号，PAC 大小、已知碱基逐字节对应与尾部长度，BWT/SA 的 64-bit little-endian header、两倍序列长度、采样间隔、彼此匹配和完整文件尺寸。全部成员摘要进入 report receipt，Commit 重算会拒绝验证后改变。文件以现有 no-follow approved resource reader 打开，并检查读取前后 stat 不变。

格式依据是 [BWA 0.7.19 bwt.c](https://raw.githubusercontent.com/lh3/bwa/v0.7.19/bwt.c)、[bwtindex.c](https://raw.githubusercontent.com/lh3/bwa/v0.7.19/bwtindex.c) 和 [bntseq.c](https://raw.githubusercontent.com/lh3/bwa/v0.7.19/bntseq.c)。v1 专门支持已声明的 BWA 0.7 64-bit little-endian 索引；不宣称验证 bwa-mem2。它检验结构、来源和 PAC 序列一致性，未重新构建整个 FM-index 或证明所有 suffix-array 位置的数学正确性。wrapped plain DNA FASTA 的单行上限 16 MiB，超出明确诊断，不静默接纳。

新测试 20 项（含参数化）覆盖实际临时 store/CAS、Supervisor 确定性验证、CompletionGate 和 Commit；被测核心均真实，仅外部执行结果和模型 reviewer 为受控输入：

- 正常产物在 attempt 开始后创建：无专用 predicate 的旧目录合同确实可把仅含 `.amb` 的 bundle 正式 Commit，补足旧审计只到 `created` 的证据边界。此为合成静默失败/成功声明见证，不重放原科学 session。
- 新合同拒 FAI-only、部分 BWA、空 BWT、错 contig、错 FAI/dict 长度、错 M5、错来源、错 PAC/AMB、截断 SA。各场景通用 artifact gate 已通过，拒绝来自真实新 predicate。
- 完整 bundle 来自实际安装工具的 384 bp 合成参考，真实 Commit 通过；验证成功后篡改 SA，Commit 重算拒绝。
- 旧未登记 bundle 仍被既有 artifact provenance gate 拒绝；未削弱产物来源或旧文件保护。Plan-local output、inputs/resource_uses 和最终 Skill loader/compile 均覆盖。

追加旧 semantic 两套测试共 36 项：共同前置基线和候选均 33 PASS / 同 3 FAIL（旧 snpEff capability 契约 1 项、旧 reviewer 夹具 2 项），无新增失败；未改旧测试求绿。主任务最终累计集成测试另行出具，不能与本局部 PASS 相加当作累计版本结果。
